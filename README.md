# TradingView Ichimoku - Strategy & Indicator

## Mô Tả / Description

**[Tiếng Việt]**

Hệ thống Ichimoku mở rộng cho TradingView với các đường Kijun bổ sung và SMMA.

**2 Phiên Bản:**
1. **Strategy (EA)** - Chiến lược tự động giao dịch với quản lý rủi ro
2. **Indicator** - Chỉ báo phân tích kỹ thuật (không giao dịch tự động)

Hệ thống bao gồm:
- Ichimoku cơ bản (9, 26, 52, 26)
- Các đường Kijun: 65 (đen), 129 (xanh dương), 172 (xanh lá), 234 (cam)
- Các đường SMMA: 52, 139, 400

**[English]**

Extended Ichimoku system for TradingView with additional Kijun lines and SMMA indicators.

**2 Versions:**
1. **Strategy (EA)** - Automated trading strategy with risk management
2. **Indicator** - Technical analysis indicator (no automated trading)

System includes:
- Basic Ichimoku (9, 26, 52, 26)
- Kijun lines: 65 (black), 129 (blue), 172 (green), 234 (orange)
- SMMA lines: 52, 139, 400

## Cách Sử Dụng / Usage

### Strategy (EA - Tự động giao dịch / Automated Trading)
1. Mở TradingView / Open TradingView
2. Mở Pine Editor / Open Pine Editor
3. Copy code từ file `tradingview_ea.pine` / Copy code from `tradingview_ea.pine`
4. Paste vào Pine Editor / Paste into Pine Editor
5. Lưu và thêm vào biểu đồ / Save and add to chart

### Indicator (Chỉ báo / Indicator Only)
1. Mở TradingView / Open TradingView
2. Mở Pine Editor / Open Pine Editor
3. Copy code từ file `tradingview_ichimoku_indicator.pine` / Copy code from `tradingview_ichimoku_indicator.pine`
4. Paste vào Pine Editor / Paste into Pine Editor
5. Lưu và thêm vào biểu đồ / Save and add to chart

**Lưu ý / Note:** Indicator chỉ hiển thị tín hiệu, không tự động giao dịch / Indicator only shows signals, does not auto-trade
