# TradingView EA - Ichimoku Multi-Kijun Strategy

## Mô Tả / Description

**[Tiếng Việt]**

EA (Expert Advisor) cho TradingView sử dụng hệ thống Ichimoku mở rộng với các đường Kijun bổ sung và SMMA.

Hệ thống bao gồm:
- Ichimoku cơ bản (9, 26, 52, 26)
- Các đường Kijun: 65 (đen), 129 (xanh dương), 172 (xanh lá), 234 (cam)
- Các đường SMMA: 52, 139, 400

**[English]**

Expert Advisor (EA) for TradingView using extended Ichimoku system with additional Kijun lines and SMMA indicators.

System includes:
- Basic Ichimoku (9, 26, 52, 26)
- Kijun lines: 65 (black), 129 (blue), 172 (green), 234 (orange)
- SMMA lines: 52, 139, 400
