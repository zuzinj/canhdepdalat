## TradingView Expert Advisor

This repository includes a professional TradingView Expert Advisor (EA) implementation for automated trading strategies.

📊 **[View TradingView EA Documentation](tradingview/README.md)**

### Quick Start

1. Navigate to the `tradingview/` directory
2. Choose from available strategies and indicators
3. Follow the documentation to import and configure on TradingView

### Available Scripts

- **MA Crossover EA**: Complete Expert Advisor with risk management
- **MA Crossover Indicator**: Basic indicator for signal visualization

For detailed usage instructions, see the [TradingView documentation](tradingview/README.md).
