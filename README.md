# Cảnh Đẹp Đà Lạt - TradingView EA

## 🎯 Giới Thiệu / Introduction

Repository này chứa bộ công cụ giao dịch TradingView hoàn chỉnh, bao gồm chỉ báo (Indicator) và Expert Advisor (EA/Strategy) để giao dịch tự động.

This repository contains a complete TradingView trading system, including an Indicator and Expert Advisor (EA/Strategy) for automated trading.

## 📁 Cấu trúc / Structure

```
tradingview/
├── indicator.pine      # Chỉ báo phân tích kỹ thuật / Technical indicator
├── strategy_ea.pine    # Expert Advisor tự động / Automated EA
├── README.md          # Hướng dẫn tiếng Anh / English guide
└── HUONG_DAN.md       # Hướng dẫn tiếng Việt / Vietnamese guide
```
